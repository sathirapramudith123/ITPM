Career Pulse - Job Vacancies Platform
Overview
Career Pulse is a modern job vacancies platform connecting job seekers with employers. This web application provides a streamlined experience for posting jobs, searching opportunities, and managing applications.

Key Features
Job Seeker Functionality
User Registration & Profiles: Secure sign-up with email verification and social login options

Advanced Job Search: Filter by location, salary range, job type, and keywords

Resume Management: Upload and store multiple resume versions

Application Tracking: Dashboard to monitor application status (Applied/Interviewed/Rejected)

Job Alerts: Customizable email notifications for new matching positions

Employer Functionality
Job Posting: Create and publish detailed job listings

Candidate Management: Review applications and download resumes

Company Profiles: Showcase employer branding and benefits

Analytics: View application metrics and job performance

Admin Features
Content Moderation: Approve/reject job postings and user accounts

Reporting: Platform usage statistics and user engagement metrics

System Configuration: Manage categories, locations, and site settings

Technology Stack
Frontend: React.js with Redux for state management

Backend: Node.js/Express REST API

Database: MongoDB with Mongoose ODM

Authentication: JWT with passport.js

Cloud Services: AWS S3 for file storage

DevOps: Docker containers, CI/CD with GitHub Actions
